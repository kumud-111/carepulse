# CarePulse

Patient-friendly web app: tap-on-body symptom checker (English, हिन्दी, தமிழ், తెలుగు, ಕನ್ನಡ, മലയാളം, मराठी, ગુજરાતી, বাংলা or ਪੰਜਾਬੀ (Hinglish was removed)), a health guide of 30+ common illnesses,
city-wise doctor directory (address, phone, fee, rating) and appointment booking.

Stack: Spring Boot 3 (Java 17) + React (Vite) + H2 database (PostgreSQL optional).

## Run (Windows PowerShell)
Terminal 1 – backend (needs JDK 17+ and Maven 3.9+):
    cd backend
    mvn spring-boot:run
Wait for "Started CarePulseApplication". Sample doctors and slots are created on first start.

Terminal 2 – frontend:
    cd frontend
    npm install
    npm run dev
Open http://localhost:5173

## Logins
- Patient: create an account from the site.
- Demo doctor: dr.sharma@carepulse.test / Doctor@123  (My records shows upcoming patients)

## Optional settings (environment variables)
- GEMINI_API_KEY  adds a short plain-language note to results. The app works fully without it.
  PowerShell: $env:GEMINI_API_KEY="your_key"
- JWT_SECRET      set a long random value before any real deployment.
- PostgreSQL: DB_URL=jdbc:postgresql://localhost:5432/carepulse DB_USER=... DB_PASSWORD=... DB_DRIVER=org.postgresql.Driver

## How safety works
- Red flags (chest pain, cannot breathe, stroke signs, heavy pregnancy bleeding, self-harm...) return EMERGENCY immediately with 112 / 108 / Tele-MANAS 14416.
- Triage is rule-based (backend/src/main/resources/data/symptoms.json). It never diagnoses or names medicines.
- Medical disclaimer is added by the server in English and Hindi.

## Data
Doctors are SAMPLE data (fictional names, addresses, phone numbers) generated by scripts/gen_data.py
(17 states, 20+ cities, 396 doctors, grouped State > City > Area). Replace data/doctors.json or load real, verified data before real use.
Re-generate: python scripts/gen_data.py, then delete backend/data/ to reseed.

## API
GET /api/symptoms, /api/conditions, /api/doctors?city=&area=&specialty=&q=, /api/doctors/meta, /api/doctors/{id}/slots
POST /api/triage | /api/auth/register | /api/auth/login
Signed in: POST /api/appointments, GET /api/appointments/mine, DELETE /api/appointments/{id}, GET /api/records/assessments
Doctor only: GET /api/doctor/appointments

## Not yet production-ready
Database migrations (Flyway), rate limiting on /api/triage, tests, real verified doctor data, medical review of content.

## Language
The whole interface is English by default. Choose English, हिन्दी, தமிழ், తెలుగు, ಕನ್ನಡ, മലയാളം, मराठी, ગુજરાતી, বাংলা or ਪੰਜਾਬੀ (Hinglish was removed) in the top bar, or while creating an account
(it is saved to the account and applied on every sign-in). Symptom names, illness names, results, buttons and messages
follow the chosen language. Regional languages currently translate the core interface (menus, hero, location labels, main buttons); other text falls back to English until translated (locales.js). Hindi is fully translated. Have a native speaker review translations.

## Location
Doctors are filtered State > City > Area. Your last choice is remembered in the browser.
If you ran an older version, the backend clears the old doctor data on start and loads the state-wise list automatically.
